# sample-sales-reporting

Sample repository used in the **GitHub User Manual – Hands-On Walkthrough**.
All data and names are made up.

## What is in this repository

| Folder    | Contents                                   |
|-----------|--------------------------------------------|
| `sql/`    | SQL scripts for sales reports              |
| `config/` | Data pipeline configuration files          |
| `tests/`  | Test scripts that check the SQL results    |
| `docs/`   | Project documentation and data dictionary  |

## Owner

Sales Reporting team. Questions: open an issue in the **Issues** tab.

## How to use

1. Open a SQL script in `sql/` and copy it into your SQL editor.
2. Run the matching test in `tests/` to check the results.
3. Propose changes through a branch and a pull request. Never edit `main` directly.

## Rules

- Never store passwords, keys or customer data in this repository.
- Connection details live in the secure vault, not in config files.
